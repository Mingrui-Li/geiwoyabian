# 给我压扁！

一款面向抖音小游戏的竖屏单指解压游戏：把日常烦恼送进液压机，压成整齐方块，最后推倒本局形成的“烦恼高塔”。

## 当前阶段

项目处于完整版本的立项与预制作阶段。目标是交付一款界面精致、内容充足、反馈丰富、可以正式运营的完整轻量游戏。灰盒和垂直切片只是降低开发风险的过程节点，不是最终交付范围。

## 已确定方向

- 平台：抖音小游戏，首发优先 Android
- 引擎：Cocos Creator 3.8.7+
- 语言：TypeScript
- 画面：竖屏 2D，软陶玩具风格
- 操作：单指长按下压，松开停止
- 单局：60–120 秒
- 技术原则：视觉假物理、数据驱动物品、平台能力隔离
- 设计流程：gpt-image-2 产出视觉素材 → Figma MCP 完成界面设计 → Cocos 1:1 实现
- 完整版范围：5 个主题、75 个关卡、至少 50 件物品、4 种游戏模式
- 永久排除：排行榜、公会、家园、剧情和多人对战

## 最近的里程碑

用 3 个灰盒物品完成“长按下压 → 形变 → 判定 → 反馈 → 进入下一个物品”的 30 秒可玩闭环；随后立即进入正式视觉方向、Figma 设计系统和完整界面流程设计。灰盒用于验证核心手感，不代表正式游戏的界面或内容规模。
