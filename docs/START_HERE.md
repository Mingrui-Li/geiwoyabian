# 新对话从这里开始

## 固定入口

1. 阅读`AGENTS.md`和`docs/STATUS.md`。
2. 阅读当前`IN_PROGRESS`工作流卡。
3. 查看`git status --short --branch`和最近提交。
4. 确认没有另一个实时窗口正在修改同一范围后，直接继续当前工作。

不要重新拆任务，不要因为换了对话就从头规划或复查已经确认的内容。

## 当前路线

```text
GWP-017 完成整套Figma UI并取得用户确认
→ GWP-030 完成整个Cocos小游戏和发布验收
```

GWP-017可以跨多个对话保持`IN_PROGRESS`。完成整套UI前不创建新任务，也不进入Cocos。GWP-017得到用户确认后，将其标记`DONE`并解锁GWP-030。

## 对话结束时

- 保存和提交可恢复的有效工作。
- 在当前工作流卡写几行：完成了什么、下一步是什么、是否有真实阻塞。
- 未完成就保持`IN_PROGRESS`；不要生成审阅任务、交接包或新的checklist。
