# GWP-003：建立平台适配层与本地空实现

## 目标

建立核心玩法可依赖但不感知抖音API的平台接口，并提供浏览器/编辑器环境可用的空实现。

## 交付物

- [ ] 定义震动、录屏、分享、激励广告、暂停与恢复接口
- [ ] 实现`NoopPlatformAdapter`
- [ ] 提供适配器注入或选择机制
- [ ] 为成功、取消、失败状态定义稳定结果类型
- [ ] 添加适用的单元检查或最小调用验证

## 验收

- [ ] 编辑器/浏览器无`tt`全局也能运行
- [ ] 调用所有空实现不会抛出未处理异常
- [ ] 核心玩法目录不存在直接`tt.*`引用
- [ ] `git diff --check`通过

## 不在本任务范围

- 不接入真实抖音录屏、分享或广告
- 不修改主场景
- 不设计平台相关UI
