# GWP-016：Figma导航与内容组件

## 目标

建立主入口、模式、关卡、图鉴、外观和奖励页面需要的导航与内容组件。

## 必须使用的技能

- `figma-use`
- `figma-generate-library`

## 组件范围

- [ ] TopBar：标题、返回、设置、资源胶囊的可组合属性
- [ ] BottomNav：模式、图鉴、外观等入口及选中/红点/禁用状态
- [ ] ModeCard：默认、选中、锁定、今日已完成
- [ ] ThemeCard：进度、锁定、完成和背景预览
- [ ] LevelCard：星级、锁定、当前、完成和奖励提示
- [ ] CollectionCell：未知、已发现、三结果进度和完成
- [ ] ItemDetailCard：物品图、材质提示、三类结果和统计
- [ ] SkinCard：未解锁、可解锁、选中、已装备
- [ ] RewardCard/UnlockPanel：普通奖励、新物品、新主题、新外观
- [ ] AchievementCard：未完成、进行中、完成、已领取

## 验收

- [ ] 每个组件逐个完成Auto Layout、变量、属性和变体
- [ ] 适用的长中文、0值、最大值和空内容状态被验证
- [ ] 没有通过复制Frame制造近似组件
- [ ] 每个组件完成metadata和独立截图验证
- [ ] STATE.json和COMPONENTS.md同步完成
- [ ] `git diff --check`通过

## 不在本任务范围

- 不组装正式屏幕
- 不创建游戏HUD专用组件
- 不修改Cocos工程
