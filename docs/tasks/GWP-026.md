# GWP-026：Figma设计冻结与开发交接

## 目标

由用户完整审阅并冻结正式设计，将精确Figma节点、资产、token、组件、屏幕、状态和动效规格整理为Cocos可以逐项实现的唯一输入。

## 必须使用的技能

- `figma`
- `figma-use`
- `figma-generate-design`
- `figma-generate-library`

## 交付物

- [ ] 用户审阅核心视觉、24类界面、全部状态、三尺寸适配和可点击原型
- [ ] 处理用户反馈并重新完成受影响屏幕的结构与截图验证
- [ ] `Dev_Handoff`仅包含已批准的精确Frame和组件版本
- [ ] `docs/figma/HANDOFF_INDEX.md`记录file URL、Section ID、每屏/组件node ID、截图、状态和版本
- [ ] `docs/figma/TOKEN_MAPPING.md`记录Figma变量到Cocos常量/样式的映射计划
- [ ] `docs/figma/COMPONENT_MAPPING.md`记录Figma组件到Cocos prefab/component的映射计划
- [ ] `docs/figma/ASSET_EXPORT.md`记录每项批准资产的节点、格式、尺寸、切片和用途
- [ ] `docs/figma/IMPLEMENTATION_ORDER.md`给出Cocos组件与屏幕实现顺序和视觉验收方式
- [ ] STATE.json标记phase=`design-frozen`、pendingValidations为空

## 设计冻结闸门

- [ ] 用户明确确认设计冻结
- [ ] 24类界面、状态、原型、响应式、动效和审计任务全部DONE
- [ ] 所有Dev Handoff链接指向精确节点，不使用模糊Page链接
- [ ] 所有资产、token和组件有唯一来源
- [ ] 没有占位图、占位文字、未解决冲突或静默近似
- [ ] `git diff --check`通过
