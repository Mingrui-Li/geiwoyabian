# GWP-018：Figma用户流程与线框原型

## 目标

使用正式组件实例组装所有关键流程的结构化线框，先验证信息架构和动作路径，再进入高保真逐屏设计。

## 必须使用的技能

- `figma-use`
- `figma-generate-design`

## 流程范围

- [ ] 首次启动→直接按压教学→首次高塔→功能解锁→主入口
- [ ] 主入口→主题→关卡→游戏→高塔→结果→下一关
- [ ] 主入口→自由解压→选物品→设置→游玩→退出
- [ ] 主入口→今日订单→游玩→完成记录
- [ ] 主入口→连续压→游玩→本地最佳→重来
- [ ] 主入口→图鉴→物品详情→三结果
- [ ] 主入口→外观/成就→解锁或装备→返回
- [ ] 结算→分享预览→发布/取消/失败→奖励结果

## 验收

- [ ] 所有节点使用组件实例，不使用一次性硬编码UI模拟正式结构
- [ ] 每个流程覆盖成功、取消、错误和返回
- [ ] 主要动作在单手拇指范围且不与长按游戏区冲突
- [ ] 用户走查并确认流程后才能进入DONE
- [ ] 每段流程完成独立截图与连接检查
- [ ] STATE.json记录全部流程Frame和验证状态
- [ ] `git diff --check`通过
