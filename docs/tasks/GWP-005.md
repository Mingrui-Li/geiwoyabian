# GWP-005：实现物品配置、形变数据与结果判定

> 2026-08-27取消：由设计冻结后的核心玩法任务重新拆解。

## 目标

用统一、数据驱动的模型描述可压物品，并根据压缩率稳定输出完美、合格、欠压和过压结果。

## 交付物

- [ ] 定义五类物品原型和类型安全配置schema
- [ ] 实现压力输入到压缩率/形变参数的映射
- [ ] 实现理想区间、破裂阈值、回弹和结果判定
- [ ] 建立纸箱、橡皮鸭、纸杯三份灰盒配置
- [ ] 提供配置校验，拒绝非法阈值或重叠区间
- [ ] 结果包含后续反馈和埋点所需数据

## 验收

- [ ] 三份配置可产生四类预期结果
- [ ] 边界值、极小/极大输入和重复结算有明确行为
- [ ] 新物品无需新增专属脚本即可配置
- [ ] TypeScript编译及配置/判定检查通过
- [ ] `git diff --check`通过

## 不在本任务范围

- 不实现液压机输入
- 不制作正式物品图片
- 不实现粒子、震屏和音效
