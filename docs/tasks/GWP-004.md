# GWP-004：实现液压机输入与压力控制

## 目标

把长按、接触、增压、松开和回升实现为可调、可观察且不依赖具体物品的液压机控制模块。

## 交付物

- [ ] 指针/触摸长按与松开输入
- [ ] 压头空程、接触后增压和回升状态
- [ ] 位置、速度、压力与压缩请求的稳定输出
- [ ] 可配置速度、加速度、最大压力和回升曲线
- [ ] 暂停、失焦和触摸取消时安全释放
- [ ] 灰盒压头prefab或独立测试场景

## 验收

- [ ] 连续快速按住/松开不会卡死或穿越状态
- [ ] 不同帧率下压力变化保持可接受一致性
- [ ] 没有具体物品ID或材质逻辑进入控制器
- [ ] TypeScript编译和灰盒交互检查通过
- [ ] `git diff --check`通过

## 不在本任务范围

- 不判定完美、欠压或过压
- 不实现物品形变
- 不加入正式视觉、音效或震屏
