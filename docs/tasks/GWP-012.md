# GWP-012：选择并固化正式视觉基准

## 目标

由用户从三套方向中确认唯一正式方向，补齐必要变体，并形成Figma变量、组件和屏幕可以直接使用的视觉基准与批准资产集。

## 必须使用的技能

- `imagegen`，仅在选定方向需要修正或补图时使用

## 交付物

- [ ] 用户明确选定唯一方向，记录选择理由和拒绝项
- [ ] `VISUAL_DIRECTION.md`：色板、轮廓、视角、光向、材质、图形语言、字体气质、禁用样式
- [ ] 主入口、游戏舞台、结算场景三张批准基准图
- [ ] 液压机、传送带、背景、物品、面板材质和装饰母题的批准版本
- [ ] `ASSET_REGISTER.md`记录资产ID、用途、状态、源文件、透明背景和Figma导入计划
- [ ] 候选、拒绝、批准资产物理分离

## 验收

- [ ] 批准资产足以开始Figma Foundations与首批组件
- [ ] 同屏缩放、色彩、轮廓和光向一致
- [ ] 用户明确批准，不允许设计窗口自行选择
- [ ] 没有文字、品牌、水印、背景残留或明显生成错误
- [ ] `git diff --check`通过

## 不在本任务范围

- 不写入Figma
- 不初始化或修改Cocos工程
