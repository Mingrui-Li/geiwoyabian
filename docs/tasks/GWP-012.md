# GWP-012：选择并固化正式视觉基准

## 目标

由用户从三套方向中确认唯一正式方向，补齐必要变体，并形成Figma变量、组件和屏幕可以直接使用的视觉基准与批准资产集。

## 必须使用的技能

- `imagegen`，仅在选定方向需要修正或补图时使用

## 已确认输入

- 用户于2026-08-27明确选择唯一主方向：B“充气贴纸工坊”（`direction-b-puffy-sticker`）。
- A“软陶工业玩具”和C“糖果机械模型”不作为主方向；除非用户再次明确指定，不混入其整套材质语言。
- 固化B时必须保留白色贴纸衬边、深墨蓝外框、偏移阴影和高手机辨识度，同时用纸箱折痕/破裂、橡皮鸭回弹、纸杯挤压/爆浆等差异化规则，避免所有材质都变成同一种气垫。
- 候选结果图的宽高比和留白只用于比较；批准的主入口、游戏舞台与结算基准必须统一到正式竖屏构图，不把候选预览留白当作最终版式。
