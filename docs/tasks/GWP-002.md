# GWP-002：建立工程架构骨架

> 2026-08-27取消：旧工程优先链被设计先行路线替代，后续架构任务必须依赖`GWP-026`。

## 目标

建立后续玩法、平台、反馈和内容可以独立演进的TypeScript目录、核心状态、配置入口和依赖边界。

## 交付物

- [ ] 建立`core`、`gameplay`、`platform`、`services`、`config`、`shared`等约定目录
- [ ] 定义游戏顶层状态与显式状态切换接口
- [ ] 建立类型安全的配置入口和开发环境配置
- [ ] 建立事件或消息边界，避免模块直接互相查找场景节点
- [ ] 建立对象池和时间/随机数等可替换服务的最小接口
- [ ] 在README或技术文档中记录目录职责

## 验收

- [ ] TypeScript编译通过
- [ ] 初始场景运行无报错
- [ ] 核心模块不依赖`tt.*`
- [ ] 没有为未来系统创建大量空类
- [ ] `git diff --check`通过

## 不在本任务范围

- 不实现具体按压玩法
- 不实现正式UI、广告、录屏或存档
- 不引入后端或第三方框架
