任务卡现在表示可跨多个对话持续推进的工作流，不再要求“一张卡一个对话”，也不再为单个组件、页面或检查创建新卡。

- `GWP-030`：实现完整Cocos小游戏并完成发布验收。

`GWP-018`至`GWP-026`已并入`GWP-017`；`GWP-031`至`GWP-037`已并入`GWP-030`，原卡保留为历史但状态为`CANCELLED`。

## 状态

- `READY`：可以开始。
- `IN_PROGRESS`：正在持续推进；新对话可在确认没有并发写入后直接续做。
- `DONE`：整个玩家可见结果完成并通过最终验收。
- `BLOCKED`：前置结果未满足。
- `CANCELLED`：已合并到更大的工作流或不再执行。

每次对话结束只需在当前卡留下几行真实进度。未完成时保持`IN_PROGRESS`，不要为了结束对话制造新任务、审阅步骤或证据包。
