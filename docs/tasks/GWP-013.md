# GWP-013：Figma工作区发现、范围锁定与状态台账

## 目标

在任何Figma设计创建前，检查共享文件、库、现有组件和编辑边界，锁定v1 token/组件范围，并建立可跨窗口恢复的节点状态台账。

## 必须使用的技能

- `figma`
- `figma-use`
- `figma-generate-library`

调用任何Figma工具前必须完整读取这些技能及其本阶段要求的Discovery参考。目标文件已存在，不调用`create_new_file`。

## 交付物

- [ ] 只读检查目标文件、共享Page、锚点`11:7101`和Section外节点
- [ ] 调用`get_libraries`，分页检查可用库后再执行按意图拆分的`search_design_system`
- [ ] 检查本地变量、远程变量、组件、样式、字体和命名约定
- [ ] 输出`FIGMA_GAP_ANALYSIS.md`：可复用、需包装、需新建以及所有冲突
- [ ] 锁定v1变量、样式和组件精确清单，并取得用户确认
- [ ] 在共享Page内创建唯一顶层Section `GWP_给我压扁`，不触碰相邻节点
- [ ] 建立`docs/figma/STATE.json`，记录file key、Page锚点、Section ID、run ID、阶段、节点ID、验证和待办
- [ ] 截图确认Section位置和编辑边界

## 验收

- [ ] 用户确认gap analysis和v1设计系统范围
- [ ] 所有Figma写入严格串行、增量执行并返回节点ID
- [ ] 新Section不覆盖、移动或重命名任何已有项目节点
- [ ] STATE.json可让新窗口通过只读检查恢复上下文
- [ ] metadata与截图验证通过
- [ ] `git diff --check`通过

## 不在本任务范围

- 不创建变量、组件或正式屏幕
- 不修改Cocos工程
