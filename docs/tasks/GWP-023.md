# GWP-023：Figma可点击原型与动效规格

## 目标

把全部关键用户流程连接成可点击原型，并为Cocos实现提供明确的状态转换、时长、缓动、层级和减少动态效果规则。

## 必须使用的技能

- `figma-use`
- `figma-generate-design`

若需要写入或检查Figma动画能力，额外加载适用的motion技能。

## 交付物

- [ ] 首次体验、闯关、自由解压、今日订单、连续压、图鉴、外观和分享可点击原型
- [ ] 成功、取消、错误、断网和恢复路径可在原型中触达
- [ ] 点击、页面切换、弹窗、解锁、奖励、完美判定和高塔结算动效规格
- [ ] `MOTION_SPEC.md`记录触发、起止状态、时长、缓动、声音/震动同步和减少动态效果替代
- [ ] 至少5名未参与设计者完成核心原型走查
- [ ] `PROTOTYPE_TEST.md`记录任务完成率、误触、迷路和理解问题

## 验收

- [ ] 所有主要流程无死路且返回逻辑一致
- [ ] 原型测试高频问题已修复并重新验证
- [ ] 动效不依赖无法在Cocos或抖音小游戏实现的能力
- [ ] STATE.json记录原型入口和验证结果
- [ ] `git diff --check`通过

## 不在本任务范围

- 不实现Cocos动效
- 不接入真实平台能力
