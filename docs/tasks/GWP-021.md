# GWP-021：Figma系统、分享、广告与异常状态界面

## 目标

完成剩余系统界面，并把所有适用的加载、空、锁定、错误、断网、取消和恢复状态设计成正式可交付界面。

## 必须使用的技能

- `figma-use`
- `figma-generate-design`

## 屏幕与状态范围

- [ ] 21 设置
- [ ] 22 录屏/分享预览：准备、可发布、发布中、成功、取消、失败
- [ ] 23 激励广告确认与奖励结果：确认、加载、成功、跳过、失败
- [ ] 24 通用确认、错误、断网和恢复弹窗
- [ ] 按STATE_MATRIX补齐前20类屏幕适用的加载、空、锁定、完成、错误和恢复状态
- [ ] 减少动态效果、音量、震动和持续显示压力条设置状态

## 验收

- [ ] 错误状态提供可执行的重试、返回或安全继续动作
- [ ] 广告和分享失败不会产生流程死路或虚假奖励承诺
- [ ] 状态差异不只依赖颜色
- [ ] 每个状态完成metadata与截图验证
- [ ] STATE.json记录节点ID、状态覆盖和验证结果
- [ ] `git diff --check`通过

## 不在本任务范围

- 不接入真实抖音API
- 不修改Cocos工程
