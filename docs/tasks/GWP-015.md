# GWP-015：Figma基础交互组件

## 目标

逐个建立后续所有屏幕依赖的基础交互组件，保证变量绑定、Auto Layout、变体和属性完整。

## 必须使用的技能

- `figma-use`
- `figma-generate-library`

必须读取component creation与component patterns参考。每次只完成一个组件，验证通过后才能开始下一个。

## 组件范围

- [ ] Button：Primary/Secondary/Danger，适用尺寸与Default/Pressed/Disabled/Loading
- [ ] IconButton：普通、强调、关闭/返回用途，含Pressed/Disabled
- [ ] Tab/Segment：Default/Selected/Disabled
- [ ] Badge/StatusPill：普通、成功、警告、锁定、完成
- [ ] Progress：线性进度、星级进度和加载状态
- [ ] Toast/InlineMessage：普通、成功、错误和断网
- [ ] Loading：启动、局部和按钮加载

## 每个组件的完成要求

- [ ] 先查询可复用组件；复用、包装或新建的理由记录在COMPONENTS.md
- [ ] 使用Auto Layout和设计变量，无硬编码颜色、间距、圆角和阴影
- [ ] variant矩阵受控，图标使用INSTANCE_SWAP而不是每图标一个variant
- [ ] 文本、布尔和实例交换属性连接到正确子节点
- [ ] 描述、用法和禁止场景写入组件说明
- [ ] metadata与独立screenshot通过
- [ ] 节点ID和验证状态同步到STATE.json

## 不在本任务范围

- 不组装正式屏幕
- 不创建游戏专用HUD组件
- 不修改Cocos工程
