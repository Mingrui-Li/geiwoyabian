# GWP-008：核心手感观察测试与P1闸门

> 2026-08-27取消：观察测试保留，但移动到Figma设计冻结和正式闭环实现之后。

## 目标

用真实观察而不是开发者主观感觉验证核心按压是否能让玩家理解、获得爽点并愿意继续。

## 交付物

- [ ] 准备统一的观察脚本和记录表
- [ ] 至少邀请5名未参与设计的人体验
- [ ] 记录首次按压时间、是否求助、连续游玩件数和口头反馈
- [ ] 记录压力条依赖、完美/失误理解和最喜欢的材质
- [ ] 汇总问题并区分手感、节奏、反馈和理解问题
- [ ] 给出`PASS`、`ITERATE`或`BLOCK`结论及证据

## P1闸门

- [ ] 新测试者无需解释能在5秒内完成第一次按压
- [ ] 至少4/5测试者愿意主动再压一件
- [ ] 至少3/5能通过形变而非只盯压力条完成合格判定
- [ ] 关闭得分和奖励后仍有重复欲望
- [ ] 30秒灰盒演示在静音下可以被旁观者理解

## 验收

- [ ] 原始观察记录与结论同时保存
- [ ] 未通过项被拆成明确返工任务，不能只写“继续优化”
- [ ] 通过后提出P2详细任务拆解建议，但不自行把状态改为DONE
- [ ] `git diff --check`通过

## 不在本任务范围

- 不为了通过测试添加成长、奖励或正式UI
- 不生成正式美术
- 不跳过失败项直接进入P2
