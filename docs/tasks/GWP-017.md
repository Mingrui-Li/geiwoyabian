# GWP-017：完整Figma UI设计与确认

## 目标

废弃当前Figma全部设计。先用Image-2完成并确认整套漂亮的游戏UI视觉母稿，再从空白状态用`figma-mcp-rust`重建为可编辑生产设计，最后交给用户整体确认。

## 最终交付

- 一套先于Figma完成并经用户确认的Image-2整屏视觉母稿。
- 依据批准母稿从空白重建的完整玩家界面：启动/教学、主页与各内容入口、选择、游戏、暂停、结算、奖励以及必要系统状态。
- 统一且有吸引力的“充气贴纸工坊”高保真视觉，不保留占位画板。
- 核心流程可理解，关键竖屏尺寸没有明显遮挡、裁切和不可读问题。
- 一张整体总览、核心Figma Frame链接和开发所需的最少资产说明。

旧`SCREEN_SPEC.md`用于防遗漏，但不强制做成24张独立画板；状态可以合并在相同页面中展示。

## 执行规则

- 全部Figma读写只使用`figma-mcp-rust`，禁止官方Figma MCP。
- 强制顺序：`Image-2出整屏图 → 用户确认 → Figma从空白实现 → 用户确认 → Cocos`，不得跳步。
- 2026-09-01前的当前Figma设计全部废弃，禁止复用其变量、样式、组件或页面构图。
- 缺少组件时在本任务内补齐，不新建任务。
- 本工作流允许跨多个对话持续推进；每次只留下简短进度，不生成新的阶段checklist。
- 完整UI给用户看过并得到明确确认后，才能标记`DONE`并解锁`GWP-030`。
