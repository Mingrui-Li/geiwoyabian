# GWP-017：Figma游戏HUD与结算组件

## 目标

建立压扁玩法、教学、判定、高塔和分享场景需要的专用组件，使游戏画面在工程开始前已经具备完整信息层级与状态语言。

## 必须使用的技能

- `figma-use`
- `figma-generate-library`

## 组件范围

- [ ] GameplayHUD：关卡、进度、连击、暂停和安全区容器
- [ ] PressureMeter：引导显示、弱提示、永久显示、危险/理想区间
- [ ] ComboBadge：0、普通、3/6/10档高潮和中断
- [ ] PressResult：完美、合格、欠压、过压
- [ ] TutorialCoachmark：按住、松开、观察形变和跳过/完成
- [ ] ItemQueue/LevelProgress：当前、剩余和最后一件
- [ ] TowerSummary：整齐度、方块数、事故物品和蓄力状态
- [ ] StarResult/ScoreSummary：0–3星、最佳和新纪录
- [ ] SharePreview：片段缩略、文案、奖励、发布/取消/失败
- [ ] PausePanel：继续、重开、设置和退出

## 验收

- [ ] 组件不会遮挡液压机、物品、高塔和主要手指区域
- [ ] 每个判定在颜色之外还具有形状、图标或文字区别
- [ ] 组件状态覆盖首次教学、普通游玩、高潮和异常中断
- [ ] 每个组件完成变量绑定、metadata和截图验证
- [ ] STATE.json和COMPONENTS.md同步完成
- [ ] `git diff --check`通过

## 不在本任务范围

- 不组装正式屏幕
- 不实现Cocos动画或游戏逻辑
