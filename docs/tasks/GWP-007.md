# GWP-007：集成三物品核心灰盒闭环

> 2026-08-27取消：不再制作先于Figma的灰盒闭环；新闭环必须使用冻结后的正式HUD、教学、结算与视觉资产。

- [ ] 纸箱、橡皮鸭和纸杯三种灰盒物品轮换
- [ ] 传送带或等价进出场节奏
- [ ] 连续10件物品的调试序列
- [ ] 简单结果与连击显示，仅作调试用途
- [ ] 30秒灰盒录屏或可复现运行说明

- [ ] 不看说明可理解按住和松开操作

- [ ] 浏览器预览与目标真机中至少一种环境完成可玩检查
- [ ] `git diff --check`通过
