# GWP-011：生成三套完整视觉方向

## 目标

使用gpt-image-2生成三套可比较的完整游戏视觉方向，让用户基于主入口、游戏舞台和结算场景做选择，而不是基于单个物品图猜测整套UI。

## 必须使用的技能

- `imagegen`

开始生成前必须完整读取该技能，并以`GWP-010`的屏幕规格与资产需求为输入。

## 每套方向必须包含

- [ ] 主入口关键视觉示意
- [ ] 游戏HUD与液压机舞台关键视觉示意
- [ ] 高塔粉碎/关卡结果关键视觉示意
- [ ] 液压机、传送带和三件代表物品
- [ ] 面板、按钮、徽章、进度条和装饰质感示意
- [ ] 背景、轮廓、主光、材质、色彩和字体气质说明
- [ ] 缩到360×800画板后的可读性预览

## 验收

- [ ] 三套方向在视觉语言上明显不同，但都满足轻松、解压、明亮和可传播
- [ ] 同一套中的UI、物品和场景属于同一个视觉世界
- [ ] 图片不包含不可用的生成文字、品牌、水印或受保护角色
- [ ] 候选图按方向分目录，未混入批准资产
- [ ] `docs/design/VISUAL_EXPLORATION.md`记录每套优点、风险和OPC生产成本
- [ ] `git diff --check`通过

## 不在本任务范围

- 不决定最终方向
- 不创建Figma组件或屏幕
- 不导入Cocos
