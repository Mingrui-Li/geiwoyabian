# GWP-011：生成三套完整视觉方向

## 目标

使用gpt-image-2生成三套可比较的完整游戏视觉方向，让用户基于主入口、游戏舞台和结算场景做选择，而不是基于单个物品图猜测整套UI。

## 必须使用的技能

- `imagegen`

开始生成前必须完整读取该技能，并以`GWP-010`的屏幕规格与资产需求为输入。

## 每套方向必须包含

- [x] 主入口关键视觉示意
- [x] 游戏HUD与液压机舞台关键视觉示意
- [x] 高塔粉碎/关卡结果关键视觉示意
- [x] 液压机、传送带和三件代表物品
- [x] 面板、按钮、徽章、进度条和装饰质感示意
- [x] 背景、轮廓、主光、材质、色彩和字体气质说明
- [x] 缩到360×800画板后的可读性预览

## 验收

- [x] 三套方向在视觉语言上明显不同，但都满足轻松、解压、明亮和可传播
- [x] 同一套中的UI、物品和场景属于同一个视觉世界
- [x] 图片不包含不可用的生成文字、品牌、水印或受保护角色
- [x] 候选图按方向分目录，未混入批准资产
- [x] `docs/design/VISUAL_EXPLORATION.md`记录每套优点、风险和OPC生产成本
- [x] `git diff --check`通过

## 不在本任务范围

- 不决定最终方向
- 不创建Figma组件或屏幕
- 不导入Cocos

## 完成记录

- 实际完成：使用内置`image_gen`生成A“软陶工业玩具”、B“充气贴纸工坊”、C“糖果机械模型”三套完整方向；每套包含主入口、游戏舞台、高塔/结果和视觉语言板，共12张候选图，并输出9张精确360×800预览。C方向首版结果图粒子过碎，已单点迭代并只保留收敛版本。
- 关键文件：`docs/design/VISUAL_EXPLORATION.md`、`design/visual-exploration/gwp-011/PROMPTS.md`、`design/visual-exploration/gwp-011/MANIFEST.md`及三个方向的`candidates/`、`previews/`目录。
- 验证与结果：候选图12张、360×800预览9张、批准目录0个；逐图检查无可读生成文字、品牌、水印或受保护角色；三套均保留右上主光、同一基准色板、代表物品与冻结信息架构；Markdown图片链接均可解析。
- 未完成/风险：所有图片仍是视觉探索候选，不能直接作为最终屏幕或Cocos资产；A需控制软陶批次质感，B需避免不同材质都趋同为气垫，C需控制透明边、高光、粒子密度和额外分层成本。本任务不选择最终方向，也不写入Figma。
- 后续选择建议：`GWP-012`应由用户基于360×800预览、核心按压欲望、分享截帧辨识和OPC生产成本只选一个主方向；若迁移其他方向特征，最多明确两项局部规则，禁止整套混用。
