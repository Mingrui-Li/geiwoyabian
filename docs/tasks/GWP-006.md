# GWP-006：实现核心反馈编排骨架

## 目标

把接触、持续受压、完美、欠压和过压事件编排成可调的视觉、声音、停顿与震动反馈，不把反馈散落在玩法组件中。

## 交付物

- [ ] `FeedbackDirector`或等价编排模块
- [ ] 接触、受压、释放、四类结果的反馈profile
- [ ] 灰盒缩放、闪白、裂纹/喷溅、震屏和命中停顿
- [ ] 临时音效播放、音高变化和并发限制
- [ ] 通过平台适配层触发震动
- [ ] 可关闭或降低震屏/震动的设置入口预留

## 验收

- [ ] 移除反馈模块后玩法判定仍能运行
- [ ] 高频连续触发不会产生无限节点或音频堆积
- [ ] 四类结果在静音和闭眼听声两种情况下都可区分至少大部分状态
- [ ] 构建与灰盒调用检查通过
- [ ] `git diff --check`通过

## 不在本任务范围

- 不制作正式音效库
- 不设计正式UI
- 不集成完整关卡流程
