# GWP-024：Figma设计系统与可访问性审计

## 目标

## 必须使用的技能

- `figma-use`
- `figma-generate-library`

## 审计范围

- [ ] 变量集合、alias、scope、code syntax和未使用token
- [ ] 硬编码fill、stroke、gap、padding、radius、shadow和字体

- [ ] 未命名、重名、命名层级和节点归属
- [ ] 字体族、字重、行高、中文可读性和文本裁切
- [ ] 对比度、触控热区、仅颜色区分、减少动态效果和错误反馈
