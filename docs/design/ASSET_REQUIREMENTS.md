# 《给我压扁！》图像资产需求

版本：1.0-draft
用途：定义 gpt-image-2 的生成范围、数量、构图和验收要求；最终排版、文字、图标和交互组件必须在 Figma 中完成。

## 1. 统一视觉与技术约束

- 风格关键词：软陶玩具、圆角工业设备、夸张材质、明亮、不写实、可触摸。
- 基准色：工业黄 `#FFC83D`、压力红 `#FF5D55`、深墨蓝 `#243145`、薄荷绿 `#63D7B0`、奶油白 `#FFF4DE`。
- 视角：游戏物品采用轻微俯视的正面 3/4 视角；主光固定来自右上方；轮廓厚度和阴影柔度保持一致。
- 背景与物品分层生成。所有可交互物品、机器部件、装饰和粒子母题优先透明背景 PNG；不得把文字、按钮、数字、品牌标识或 HUD 画进图片。
- 物品至少提供 `idle`、`compressed`、`under`、`over` 四类关键状态视觉参考；它们用于 Figma 定义目标和指导运行时变形，不是逐件生成完整动画。`perfect` 可复用 `compressed` 并由引擎加轮廓，事故结果必须有独立参考。
- 生成图是视觉输入，不是最终资产。进入 Figma 前需要去字、清理透明边、统一调色、统一视角和裁切；采用状态由 Figma 实屏效果决定。
- 主画面适配 360×800、375×812、393×873。背景四周额外保留至少 12% 可裁切区；主要物体不得贴边。
- @2x 输出优先；需要在 Cocos 变形的对象必须保留足够透明边距，不预烘焙无法分离的投影。

## 8. 文件、命名与验收

- 单物品源图为 1024×1024 PNG 透明背景；本清单 ID 写入资产台账，文件名使用对应小写英文，例如 `item_desk_alarm_clock_idle_v01.png`。候选稿进入 `candidates/`，批准稿进入 `approved/`，禁止用“最终版2”。
- 生产按 4–6 件同类物品分批；首批六件固定为快递纸箱、橡皮鸭、纸杯、震动闹钟、缠绕耳机和咖啡杯，并始终附带用户选定的视觉基准图。
- 每批记录提示词、种子/参考图、生成日期、裁切与调色说明、批准状态。
- 同批物品检查：视角、光向、轮廓、透明边、接触阴影和饱和度一致。
- 缩到 96×96 时仍能辨认物品；在 360×800 游戏舞台中不得与压头或背景融合。
- `idle` 到 `compressed` 的轮廓变化必须可被确定性变形和遮罩复现；不依赖真实软体模拟。
- 任何带伪文字、乱码、额外肢体、无法分层投影或不一致视角的生成物不得进入批准区。
