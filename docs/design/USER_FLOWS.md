# 《给我压扁！》完整用户流程

版本：1.0-draft
约定：`Sxx` 对应 `SCREEN_SPEC.md`。每条流程均覆盖开始、成功、取消、失败和返回。

## F01 首次体验

**开始**

`冷启动 → S01 启动加载 → S02 闹钟/橡皮鸭/纸杯直接按压 → S03 三块高塔粉碎 → S04 功能入口解锁`

**成功路径**

1. S01 完成资源加载，10 秒目标计时从首次可交互开始。
2. S02 玩家长按并松开；结果无论完美、合格、欠压或过压都算完成一件。
3. 三件完成后 S03 教玩家蓄力并粉碎高塔。
4. S04 一次展示 3 星、闹钟图鉴和四项主导航。
5. 玩家点“开始第 1 关”进入 S09，或“先逛逛”进入 S05。

**取消/返回**

- 首次教学不可跳过，防止完整导航出现却不知道核心操作。
- 系统返回只触发“要退出游戏吗？”；取消后回当前教学状态。
- 应用切后台自动暂停，回前台后从当前物品按压前恢复。

**失败/恢复**

- 玩家欠压或过压：展示喜剧结果后继续下一件，不弹失败框。
- 当前物品资源加载失败：S24 提供“重新加载”和“退出游戏”；重试只重载当前物品。
- 断网但资源已缓存：完整离线继续；未缓存则在 S01 重试，不创建半完成进度。
- S04 奖励写入失败：保留会话奖励并重试，成功前不重复播放发奖动画。

## F02 压扁之旅（主关卡）

**开始**

`S05 继续关卡 → S09 游戏 HUD`，或 `S05 → S07 主题 → S08 关卡 → S09`。

**成功路径**

1. S05 默认聚焦下一关；玩家也可经 S07/S08 选择已解锁关卡。
2. S09 完成 8–12 件物品；欠压和过压只影响分数、连击和塔形。
3. 最后一件进入 S11；玩家蓄力粉碎高塔。
4. S12 展示星级、分数和结果分布，存档成功后开放“下一关”。
5. 如有重大解锁进入 S13；完成奖励动作后回下一关、主题或来源页。

**取消/返回**

- S07/S08 返回时保持主题、关卡选择和滚动位置。
- S09 点暂停进入 S10；“继续压”回精确游戏状态。
- “重新开始”需 S24 确认，确认后清除本局临时成绩并重载同关。
- “退出本关”需确认，回 S08；已完成物品不计入正式进度。

**失败/恢复**

- 没有传统失败；关卡始终可完成。
- 单件资源失败：重试，或“跳过这件”；跳过不计成绩、不破坏连击并记录诊断。
- 存档失败：S12 保留结果，按钮为“重新保存”；玩家可返回 S05，但顶部提示继续重试。
- 切后台：自动 S10；恢复本局或退出，禁止在按压中直接续算压力。
- 断网：完整主关卡、结算、进度均本地可用；分享与广告单独受限。

## F03 自由解压

**开始**

`S06 模式选择 → S16 自由解压设置 → 自由解压 HUD 变体`，或 `S15 物品详情 → S16`。

**成功路径**

1. 玩家从已发现物品中选择 1–10 件，可选“随机 5 件”。
2. 设置传送速度、压力提示强度和是否重复循环。
3. 点“开始解压”，无限循环所选物品，不计星级、不产生失败。
4. 暂停时可以“换一批”，回 S16 保留设置；重新开始进入新队列。

**取消/返回**

- S16 返回 S06 或 S15，保持物品选择但不自动开始。
- 游戏内暂停后“结束解压”直接回 S16，无成绩损失确认。

**失败/恢复**

- 未选择物品：主按钮禁用并显示“至少选 1 件”。
- 选中物品资产损坏：从队列移除该件并提示，可继续其他物品或回 S16。
- 切后台：自动暂停；回前台恢复到下一件开始前。
- 断网：全部功能本地可用。

## F04 今日订单

**开始**

`S05 今日订单卡 / S06 模式选择 → S17 今日订单 → 今日订单 HUD 变体`。

**成功路径**

1. S17 展示日期、固定 12 件清单和一个轻量规则变化。
2. 玩家点“开始订单”，完成全部 12 件和高塔粉碎。
3. S12 订单结果变体展示个人成绩和当日首次完成奖励。
4. 返回 S17 后显示“今日已完成”和“再做一次”；重复挑战只更新个人最佳。

**取消/返回**

- 开始前返回来源页，不消耗任何次数。
- 进行中经 S10 退出，确认后回 S17；未完成记录可显示但不发奖励。
- 结果页可回 S17 或分享，不强制进入主关卡。

**失败/恢复**

- 在线刷新失败但有当日缓存：以缓存种子开始，并显示“使用已缓存订单”。
- 无缓存且断网：提供“重新连接”和“玩普通关卡”；不得生成与服务器日期冲突的临时订单。
- 跨日恢复未完成订单：允许完成旧订单但标记“昨日未完成”，不占用今日首次奖励；随后刷新今日订单。
- 切后台：恢复到当前物品前，已完成物品保留。

## F05 连续压

**开始**

`S06 模式选择 → S18 连续压说明 → 连续压 HUD 变体`。

**成功路径**

1. S18 展示本地最佳和速度阶段。
2. 玩家连续完成物品；每 5 件提升一级传送速度。
3. 首次欠压或过压结束本局；合格可继续但重置完美连击。
4. 返回 S18 结果态，展示件数、完美连击和是否刷新本地最佳。
5. 玩家可“再来一次”或“返回模式”。

**取消/返回**

- 开始前返回 S06。
- 进行中暂停后“结束本局”需确认；确认按当前成绩结算，不记录为异常失败。

**失败/恢复**

- 欠压/过压是设计内结束条件，不显示惩罚性“失败”，文案为“这次压到这里”。
- 资源错误中断时不更新最佳，提供“从本局开始重试”或返回 S18。
- 切后台超过 30 秒：直接按中断前成绩结算，避免恢复后节奏不公平；30 秒内从下一件前恢复。
- 本地记录保存失败：会话内保留新纪录并持续重试。

## F06 烦恼图鉴

**开始**

`底部图鉴 → S14 烦恼图鉴 → S15 物品详情`。

**成功路径**

1. S14 默认显示全部主题和总进度，可按主题或“未完成”筛选。
2. 玩家打开已发现物品进入 S15。
3. 在完美、欠压、过压三个结果页间切换，查看最佳记录和材质提示。
4. 点“压一次”进入 S16，或“去来源关卡”进入 S08。
5. 返回 S14 时恢复原筛选与滚动位置。

**取消/返回**

- S15 返回 S14，不丢筛选。
- S14 是底部导航根页；切换导航离开，再回来恢复最近筛选。

**失败/恢复**

- 无任何发现：S14 空状态提供“去完成首次按压”。
- 结果未发现：显示剪影和明确条件，不视为错误。
- 缩略图加载失败：使用材质轮廓占位，名称、完成度和详情入口仍可用。
- 存档读取错误：先显示最近快照，S24 提供“重新读取”；不把未知项误标为未发现。

## F07 液压机外观

**开始**

`底部外观 → S19 液压机外观`，或 `S13 新外观奖励 → S19`。

**成功路径**

1. 玩家在“液压机/工坊”分页切换，浏览已解锁和锁定卡片。
2. 点已解锁卡在舞台即时预览；点“使用”写入本地设置。
3. 成功后卡片显示“使用中”，后续游戏舞台使用该表现。
4. 从奖励入口进入时，“立即使用”直接完成选择并回来源页。

**取消/返回**

- 未点“使用”就切换页面时丢弃临时预览，继续使用原外观。
- “恢复默认”需普通确认，不影响解锁记录。
- 底部导航切换离开，返回时保持分类但恢复已应用外观。

**失败/恢复**

- 资产加载失败：预览退回默认外观，卡片显示“资源待修复”并提供重试。
- 设置保存失败：视觉暂时应用，提示“下次启动可能恢复原外观”，提供重试。
- 断网：已下载外观可完整使用；未下载的已解锁外观显示“联网下载”。
- 恢复：保留已应用外观，不保留未确认的临时预览。

## F08 录屏与分享

**开始**

`S12 分享精彩 → S22 录屏/分享预览`；也可从今日订单或成就完成卡进入同一预览。

**成功路径**

1. S22 组合 3–5 个精彩片段和倒塔结尾，默认 12 秒。
2. 玩家预览、切换三张无文字封面、选择是否静音预览。
3. 点“发布到抖音”，调用平台分享；平台返回成功。
4. S22 显示“分享成功”，点“返回结果”回 S12；S12 显示一次 Toast。

**取消/返回**

- 生成中可取消并回 S12，不删除本局结果。
- 平台分享面板取消后回 S22，预览和封面选择保留。
- S22 系统返回先回 S12，不触发退出游戏。

**失败/恢复**

- 无视频片段：生成静态成绩卡，主动作改为“分享成绩卡”。
- 平台不支持录屏：禁用视频发布但保留成绩卡分享。
- 断网：保留预览，提供“网络恢复后重试”和“返回结果”。
- 发布失败：说明未发布，不伪装成功；可重试或返回。
- 应用从平台面板恢复时查询分享回执；未知状态显示“未确认是否发布”，不发分享成功奖励。

## 3. 跨流程返回与冲突规则

- 任何详情页返回时必须恢复来源页的选择、筛选和滚动位置。
- 游戏进行中只允许通过 S10 离开，平台生命周期事件也转为 S10，不直接跳主入口。
- S13、S23、S24 均为单层模态；若同时触发，优先级为 `恢复/错误 > 奖励结果 > 解锁奖励`，后续模态排队而非堆叠。
- 分享、广告、在线刷新失败不得回滚已完成的本地关卡、奖励或图鉴记录。
- 所有“清除”“放弃本局”“重新开始”动作必须二次确认；普通返回和取消不二次确认。
