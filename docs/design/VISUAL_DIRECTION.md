# 《给我压扁！》正式视觉方向：充气贴纸工坊

版本：1.0
任务：GWP-012
状态：已批准为 Figma 设计输入；不等同于 Figma 设计冻结

## 1. 方向决策

### 1.1 用户选择

用户于 2026-08-27 明确选择 B“充气贴纸工坊”（`direction-b-puffy-sticker`）作为唯一正式主方向。这个选择事实来自用户确认；以下选择依据由 GWP-011 的同条件比较结果归纳，不冒充用户逐字陈述：

- 三套中在 360×800 下轮廓识别最快，机器、物品和结果动作缩小后仍清楚。
- 白色贴纸衬边、深墨蓝模切外框和偏移阴影容易贯穿游戏舞台、卡片插画、图鉴缩略图与分享截帧，传播辨识度强。
- 大色块、有限高光和贴纸式反馈适合 2D Sprite、Tween、遮罩与受控粒子，单人生产与运行时实现成本可控。
- 方向足够活泼，但只要限制缝线密度和材质同质化，就能同时承载“工业机器的重量感”和“日常物品的喜剧感”。

### 1.2 拒绝项

- A“软陶工业玩具”不作为主方向：手作颗粒和边缘不完美容易在跨批次生成时漂移，缩小后也更容易显脏。A 仅保留为历史比较材料，不吸收其整套软陶语言。
- C“糖果机械模型”不作为主方向：透明树脂、折射、高光与图层排序会提高 OPC 清理、视频压缩和 Cocos 复现成本。C 仅保留为历史比较材料，不吸收其整套通透树脂语言。
- 未经用户再次明确指定，不把 A 或 C 的材质、光影或轮廓体系混入 B。

### 1.3 设计源优先级

发生冲突时按以下顺序判断：

1. 本文件中的明确规则。
2. `design/approved/gwp-012-puffy-sticker/` 中的批准资产。
3. `docs/design/ASSET_REGISTER.md` 中的用途和导入限制。
4. GWP-011 的 B 候选图，仅用于追溯探索过程，不作为正式实现依据。

## 2. 核心视觉承诺

- 关键词：充气贴纸、圆角工业工坊、清晰模切轮廓、轻快回弹、明亮大色块、幽默但不幼稚。
- 第一眼先读到“机器正在压物品”，第二眼再读到材质差异和装饰细节。
- 同屏所有前景对象属于同一个贴纸世界，但对象本体材质不能都变成气垫。
- 生成图片只提供插画、质感和构图基准；正式文字、数字、图标、组件、状态和响应式排版仍由 Figma 完成。

## 3. 色板与使用比例

| 角色 | 色值 | 主要用途 | 限制 |
|---|---|---|---|
| Industrial Yellow | `#FFC83D` | 液压机、主按钮材质、奖励强调 | 不铺满整屏；与深墨蓝结构共同出现 |
| Pressure Red | `#FF5D55` | 按压、危险、过压、强反馈 | 只作动作焦点或警告，常态占比应低 |
| Deep Ink Blue | `#243145` | 模切外框、机器结构、主文字 | 不替换为纯黑；大背景避免整片深色 |
| Mint | `#63D7B0` | 工坊背景、清爽状态、传送带护栏 | 作为主要环境色时用奶油白拉开前景 |
| Cream | `#FFF4DE` | 背景、面板、留白、纸杯基色 | 面板与背景相邻时必须靠描边或层级区分 |
| Highlight White | `#FFFFFF` | 贴纸衬边和受控高光 | 不用作大面积纯白背景 |

构图色量建议：背景以薄荷绿和奶油白为主；工业黄承担第一视觉焦点；压力红通常不超过一屏视觉面积的约 10%；深墨蓝主要负责结构与对比。具体 Figma token 名称、scope 与数值在 GWP-014 建立。

## 4. 轮廓、衬边与阴影

- 所有主要前景插画使用“双层轮廓”：对象外先留清晰白色贴纸衬边，再加深墨蓝模切外框。
- 360 宽基准下，大型对象建议以约 4–6 设计像素白衬边和 3–4 设计像素深色外框起测；小型图鉴对象可降低到约 3–4 与 2–3，但必须在 96×96 下仍闭合。
- 轮廓必须沿整体剪影，不给内部每个零件重复套白边。内部结构用深墨蓝分缝、遮挡和明暗关系区分。
- 背景墙面、工作台和大面积环境层不重复套整圈贴纸边，避免画面像许多独立卡片拼贴。
- 偏移阴影固定向左下或正下略偏左，浅、短、边缘柔和；不得用黑色硬投影或长透视阴影。
- 透明资产的阴影必须收在画布安全区内，并保留真实 alpha；伪棋盘格、白底残留和灰色矩形底均不可批准。

## 5. 视角、比例与光向

- 机器、传送带和可压物品统一使用轻微俯视的正面 3/4 视角。
- 主光固定来自右上方；左下侧形成短而柔的体积暗部，同屏不得出现第二个反向主光。
- 造型优先大轮廓和少量结构面，避免依赖微小纹理表达材质。
- 单物品完整居中，四周至少保留 12% 透明安全区；变形、裂片、喷溅和回弹需要额外运动余量。
- 屏幕基准使用 360×800；375×812 与 393×873 的适配由后续 Figma 画板验证。GWP-012 批准整屏源图统一为 841×1870，并另存精确 360×800 可读性预览。

## 6. 材质体系

### 6.1 机器与工坊结构

- 机器主体采用光滑充气乙烯基与圆角烤漆结构的混合观感：体块饱满，缝线只出现在能解释结构或受力的外缘。
- 警示条、活塞、底座和关节依靠清楚分块表达，不用写实金属划痕、铆钉噪声或大量缝线。
- 背景用大面积奶油白/薄荷绿软垫墙、圆角灯具、线缆和孔板表达工坊；中央舞台保持安静。

### 6.2 五种物品原型

| 原型 | 静止材质与轮廓 | 受压表达 | 禁止同质化做法 |
|---|---|---|---|
| 脆性 `brittle` | 清晰平面、折面、硬壳拼接或纸张纤维；外部仍用贴纸衬边 | 先抵抗，后出现少量大裂面与圆润碎片 | 不加充气缝线，不用整体软鼓包替代断裂 |
| 弹性 `elastic` | 饱满圆体、软胶高光、少量模压接缝 | 纵向压缩时横向膨胀，松手有明确回弹过冲 | 不画纸张折痕或硬裂纹 |
| 爆浆 `squishy` | 薄壁包装、软纸/软袋褶皱、可读的液体容积 | 越压越鼓，过压从预设缝或开口喷出受控扇面 | 不把容器做成均匀气垫；静止态不提前泄漏 |
| 嵌套 `nested` | 盖、胶带、抽屉、包装缝等可开启结构清楚 | 外层打开后子物件按预设轨迹弹出 | 不在 idle 态提前露出内部内容 |
| 不稳定 `unstable` | 轻微非对称、松动部件、可读重心或抖动附件 | 理想区移动由姿态、摆动或重心变化提示 | 不靠随机高光、噪声或无意义粒子表达不稳定 |

首批材质锚点固定为：快递纸箱验证脆性/嵌套，橡皮鸭验证弹性，纸杯验证爆浆。三者共享贴纸衬边和光向，但本体表面规则必须不同。

## 7. 三张正式构图基准

### HOME

- 顶部约 10% 保持安静，供 Figma 放置标题或系统安全区内容。
- 机器与传送带形成上半屏主视觉；纸箱为首要物品，鸭子和纸杯作为次级世界提示。
- 下半屏预留一块大型空白主卡和四个底部入口表面；它们只表示材质与层级，后续必须用 Figma 组件重建。

### GAME

- 完整压机位于上中部，压头抬起；纸箱严格位于压头与传送带的共同中心。
- 顶部 HUD 安全带、中央物品形变区和下方约 26% 的长按热区均不被面板遮挡。
- 鸭子和纸杯只在传送带边缘排队，不抢夺当前物品焦点。

### RESULT

- 高塔与冲击锤完整放入正式 9:20 竖屏，不继承候选图的宽构图或等比留白。
- 高塔使用 8–10 个大块，方向清楚地向左倾倒；锤、接触点、平台和大块粒子在 360×800 下可辨。
- 只用少量宽压力弧、圆润方块纸屑和软尘团；禁止尖碎片与细小粒子云。
- 下方空白结果面板只表达材质，分数、星级、按钮和统计必须由 Figma 组件叠加。

## 8. UI 图形语言

- 面板：奶油白充气表面，有限周边缝线，白衬边、深墨蓝外框和短偏移阴影；大面积正文区保持低纹理。
- 主动作表面：工业黄；次动作表面：奶油白；危险动作由 Figma 语义色决定，不直接复用生成位图。
- 进度：奶油白槽体、薄荷填充、深墨蓝闭合边；状态文字和数值始终由 Figma/引擎渲染。
- 图标：24×24 及以下由 Figma 矢量绘制；保持大圆角、粗轮廓和少节点，不从生成图裁出功能图标。
- 品牌与反馈母题：向下压力箭头、被压扁的圆角方块、宽压力波、四向冲击、金色圆角方块纸屑和双侧回弹波。
- 所有按钮、卡片、导航与进度条必须在 Figma 中绑定变量、Auto Layout 和状态变体；批准的 UI 位图只作质感参考。

## 9. 字体气质

- 展示标题：高字面、宽字腔、粗圆角中文黑体气质；短句有弹性，但不使用幼儿手写体、泡泡字或漫画拟声字。
- 页面标题与数字强调：紧凑有重量，数字应易于快速比较；后续优先检查等宽数字或稳定字宽。
- 正文与说明：中性、克制的圆角无衬线，不能为了“贴纸感”牺牲小字号可读性。
- 本阶段不选择正式字体，也不把任何文字烘焙进图片；字体名称、授权和变量由 GWP-014 决定。

## 10. 动效与反馈气质

- 贴纸层级通过短位移、轻缩放和偏移阴影变化表达，不使用持续漂浮制造噪声。
- 弹性物品可有一次明显回弹过冲；脆性物品在临界点前保持，之后用少量大块断裂；爆浆使用方向受控的扇面。
- 完美反馈使用短停顿、金色轮廓、四向冲击和少量方块纸屑；欠压使用双侧回弹波；过压使用压力红警示波与材质专属事故接口。
- 所有形变应可由 Sprite 缩放、遮罩、换图、粒子和 Tween 确定性复现；不引入软体模拟。

## 12. 禁用样式

- 软陶指纹、手捏颗粒、随机凹痕或粗糙泥边。
- 透明糖果树脂、折射、玻璃碎片、镀铬科幻高光。
- 写实工厂、油污、锈蚀、暗色恐怖氛围或真实液压伤害。
- 纯黑细描边、多个互相竞争的轮廓层、长硬阴影。
- 所有物体都用同密度缝线、同膨胀程度和同一种软垫变形。
- 细碎高频粒子、尖锐碎片、密集装饰、背景伪文字或真实品牌。
- 将生成图中的空白面板直接当成最终按钮、导航、HUD 或可发布界面。
- 将 GWP-011 的候选预览、A/C 候选或本任务拒绝稿导入 Figma `Dev_Handoff`。

- GWP-013 可将批准图导入目标 Section 的参考区，但不得在本任务中提前写入 Figma。
- 整屏基准用于锁定构图、比例、色量和层级，不是最终界面截图。
