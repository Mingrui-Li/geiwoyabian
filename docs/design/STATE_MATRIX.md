## 1. 状态定义

| 代码 | 状态 | 定义 | 通用处理 |
|---|---|---|---|
| D | 默认 | 数据可用且玩家可执行主要动作 | 展示主动作和当前进度 |
| L | 加载 | 正在读取资源、存档、视频或平台能力 | 保留上下文；超过 8 秒才显示重试 |
| E | 空 | 合法但没有可展示内容 | 说明如何产生内容，提供可执行入口 |
| K | 锁定 | 功能或内容尚未满足解锁条件 | 明示条件与去完成条件的入口 |
| C | 完成 | 屏幕目标或全部内容已经完成 | 展示成果和下一项可做动作 |
| X | 错误 | 读取、保存、资源或平台调用失败 | 说明影响；提供重试和安全返回 |
| O | 断网 | 网络不可用或在线能力不可用 | 本地优先；仅限制需要网络的动作 |
| R | 恢复 | 应用回前台、异常退出后可恢复上下文 | 默认保留本局/选择，明确恢复或放弃 |

`—` 表示该状态对屏幕语义不成立，而不是遗漏。通用错误、断网和恢复的具体弹窗均由 S24 承载。

## 4. 状态验收规则

- 每个 `✓` 状态必须在后续 Figma 屏幕或组件变体中有节点，不以文字批注替代可见状态。
- 状态切换不改变主要按钮位置；加载只替换内容或按钮标签，避免误触。
- 错误和断网弹窗最多两项动作：恢复优先，安全返回其次。
- 恢复必须幂等：不得重复发奖励、重复扣次数或重复写成绩。
- 空状态必须指向产生内容的路径；锁定状态必须说明可验证的解锁条件。
