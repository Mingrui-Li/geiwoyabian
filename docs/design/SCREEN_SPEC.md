# 《给我压扁！》完整屏幕规格

版本：1.0-draft
任务：GWP-010
基准画板：360×800；验证画板：375×812、393×873

## 1. 全局体验约定

### 1.1 信息架构与主导航

首次三件教学完成前不展示完整导航。完成后，常驻底部导航固定为四项：

1. `闯关`：默认页，承载继续关卡、主题和关卡入口。
2. `模式`：自由解压、今日订单、连续压。
3. `图鉴`：物品收集与三类结果记录。
4. `外观`：液压机和工坊背景。

`设置`固定在非游戏主页面右上角；`成就`固定为主入口右上区域的奖杯按钮。游戏中不显示底部导航。返回规则为：弹窗先关弹窗，详情先回来源列表，列表页回所属主导航根页；根页不提供误触退出按钮，由平台系统返回键触发退出确认。

### 1.2 舞台、HUD 与触控区

- 顶部 HUD 只放关卡/物品进度、暂停和必要的压力信息；避开状态栏、抖音胶囊区，并保留至少 8 设计单位间距。
- 压头、物品、高塔及其结果反馈占据中央舞台；持久 UI 不覆盖舞台中心 45% 宽度。
- 游戏屏幕中下部设置连续长按操作区，宽度至少为画板的 72%，高度至少 240；不放会抢夺手势的按钮。
- 所有可点击元素的逻辑热区至少 44×44；视觉图标可以小于热区。
- 底部主按钮与底部导航避开系统手势区；安全区变化时向内收缩，不压缩文字或热区。
- 360×800 为排版基准；375×812 增加水平留白；393×873 优先扩展舞台和列表可视区，不放大导航与弹窗。
- 最窄 320 宽仅作破版检查：卡片改为单列、文字最多两行、主要按钮不得低于 44 高。

### 1.3 数据与状态约定

- 本规格中的关卡、星数、数量与时间均为可直接放入设计稿的数据样例。
- 加载超过 8 秒才出现“重新加载”；短暂加载只显示进度和取消/返回（若流程允许）。
- 离线时本地玩法和按本机日期生成的今日订单继续可用；仅广告、分享发布等平台能力显示离线限制。
- 错误必须同时提供恢复动作与安全返回动作，禁止只有“知道了”的死路。
- 组件编号引用 `COMPONENT_INVENTORY.md`；资产编号引用 `ASSET_REQUIREMENTS.md`。

## 2. 24 类屏幕

### S01 启动与资源加载

- 目标：快速进入首次互动或恢复到主入口，并说明必要资源的加载进度。
- 入口：小游戏冷启动、前后台恢复后资源失效、版本更新。
- 信息层级：品牌插画 `ILL-BOOT-01` → “正在搬来液压机…” → 百分比/当前资源包 → 弱提示“首次加载约 12 MB”。
- 主要动作：加载完成自动进入 S02（新玩家）或 S05（已有进度）。
- 次要动作：加载超过 8 秒显示“重新加载”；断网且已有本地资源时显示“先玩已下载内容”。
- 出口：成功到 S02/S05；重试留在本屏；不可恢复错误到 S24；系统返回触发退出确认。
- 元素映射：`A-Progress`、`A-Button/Secondary`、`C-LoadingPanel`；`ILL-BOOT-01`、`DEC-BRAND-01`。

### S02 首次直接按压教学

- 目标：让新玩家在启动后 5 秒内理解长按，并在 10 秒内获得第一次明显爽点。
- 入口：首次启动加载完成；清除教学记录后重玩。
- 信息层级：震动闹钟 `ITM-DESK-01` → 指令“按住，压扁它” → 压力条与理想区 → 1/3 进度。
- 主要动作：在中下部任意位置长按、松开完成按压。
- 次要动作：第三次无输入后出现手指演示；右上角仅有声音按钮，不提供跳过。
- 出口：单件结果后自动进入下一件；三件完成进入 S03；平台中断自动暂停并从当前物品恢复。
- 状态/反馈：首次按下进入 0.75 倍速；无论结果都继续；过压使用喜剧反馈而非失败弹窗。
- 元素映射：`G-PressHUD/Tutorial`、`G-PressureBar/AlwaysOn`、`G-ItemProgress`、`A-IconButton`；`ITM-DESK-01/02/03`、`FX-PRESS-*`。

### S03 首次高塔结算

- 目标：用三块结果方块完成第一次倒塔高潮，并教会蓄力释放。
- 入口：S02 第三件物品结算完成。
- 信息层级：三层高塔 → “按住蓄力，松手出击” → 蓄力环 → 预计奖励“最高可得 3 星”。
- 主要动作：长按蓄力，松开冲击锤。
- 次要动作：无；蓄满 2 秒未释放时以脉冲提示松手，不自动代打。
- 出口：倒塔动画结束进入 S04；应用切后台则冻结蓄力并返回时继续。
- 状态/反馈：蓄力不足仍触发轻击和幽默倒塌；首次不会失败。
- 元素映射：`G-TowerHUD/Tutorial`、`G-ChargeRing`、`G-TowerStack`；`MCH-HAMMER-01`、`FX-TOWER-*`。

### S04 功能入口解锁提示

- 目标：庆祝完成教学，并一次性介绍正式导航，不制造多层奖励弹窗。
- 入口：S03 动画结束。
- 信息层级：“液压机开工！” → 获得 3 星与闹钟图鉴 → 四个入口依次亮起 → 说明“继续闯关，解锁更多烦恼”。
- 主要动作：“开始第 1 关”。
- 次要动作：“先逛逛”进入 S05；点击新入口只播放一次简短说明。
- 出口：主动作进入 S09 的第 1 关；次动作进入 S05；系统返回进入 S05。
- 元素映射：`C-RewardModal/FeatureUnlock`、`C-NavPreview`、`A-Button/Primary`；`ILL-UNLOCK-01`、`ICO-NAV-*`。

### S05 主入口

- 目标：让玩家一眼看到下一关、总体进度与常用入口。
- 入口：已完成教学的启动、底部“闯关”、关卡结果返回。
- 信息层级：当前工坊“桌面乱成团 4/15” → 大卡“继续第 5 关：耳机别打结” → 星数 9/45 → 今日订单提醒 → 最近解锁。
- 主要动作：“继续第 5 关”。
- 次要动作：主题选择、关卡选择、成就、设置、今日订单卡、底部四项导航。
- 出口：S09、S07、S08、S20、S21、S17 或其他导航根页。
- 数据样例：体力/门票不出现；本地存档时间显示“刚刚保存”。
- 元素映射：`C-JourneyHeroCard`、`C-ThemeProgress`、`C-DailyTeaser`、`C-ResourceCapsule`、`C-BottomNav`、`C-TopBar/Home`；`BG-WORKSHOP-01`。

### S06 模式选择

- 目标：解释三种非默认玩法并清楚标示解锁条件。
- 入口：底部“模式”。
- 信息层级：模式标题 → 三张模式卡：自由解压、今日订单、连续压 → 各自一句规则和本地记录。
- 主要动作：进入选中的已解锁模式。
- 次要动作：查看锁定条件；底部导航。
- 出口：S16、S17、S18；返回/再次点“模式”保持根页；切换底部导航到对应根页。
- 数据样例：自由解压“已解锁 8 件”；今日订单“今日 0/12”；连续压“最佳 17 连击”。
- 元素映射：`C-ModeCard`、`A-LockBadge`、`C-BottomNav`、`C-TopBar/Page`；`ILL-MODE-01/02/03`。

### S07 主题选择

- 目标：查看五个主题工坊的进度、奖励和解锁条件。
- 入口：S05 当前主题卡、S08 顶部主题入口。
- 信息层级：主题横向卡片 → 星数/完成度 → 代表物品与主题奖励 → “查看关卡”。
- 主要动作：“查看关卡”。
- 次要动作：左右切换主题、查看锁定条件、返回。
- 出口：已解锁主题到 S08；锁定主题停留并显示条件；返回 S05。
- 数据样例：桌面乱成团 9/45 星；厨房别炸锅“获得 30 星解锁”；其余主题依次显示实际阈值。
- 元素映射：`C-ThemeCard`、`A-Progress`、`A-LockBadge`、`C-TopBar/Page`；`BG-WORKSHOP-01..05`、`DEC-THEME-*`。

### S08 关卡选择

- 目标：在单个主题内选择 15 关，并理解星级、完成和锁定关系。
- 入口：S07、S05 的关卡选择次入口、关卡结果的“选关”。
- 信息层级：主题标题与 9/45 星 → 15 张关卡卡 → 当前关详情条 → “开始”。
- 主要动作：开始选中关卡。
- 次要动作：切换关卡、切换主题、返回。
- 出口：S09；返回 S07 或来源页；锁定关点击后留在本屏展示“再获得 3 星解锁”。
- 数据样例：第 5 关“耳机别打结”，10 件物品，最佳 2 星，最佳分 8,460。
- 元素映射：`C-LevelCard`、`C-LevelDetailBar`、`A-StarRating`、`C-TopBar/Page`；`BG-WORKSHOP-01..05`。

### S09 游戏 HUD

- 目标：在不遮挡舞台和手势区的前提下传达关卡进度、压力、连击与暂停。
- 入口：S04、S05、S08、S12 的下一关；各模式开始后复用相应 HUD 变体。
- 信息层级：顶部“第 5 关 · 3/10”与暂停 → 压力条/理想区 → 当前连击“完美 ×3” → 中央舞台 → 中下部长按区。
- 主要动作：长按与松开控制压头。
- 次要动作：暂停；无其他可点控件。
- 出口：每件完成留在 S09 并装载下一件；最后一件到 S11；暂停到 S10；资源错误到 S24。
- 状态/反馈：欠压、过压只在舞台上显示 700ms 结果标签；不弹窗；断网不阻止本地关卡。
- 元素映射：`G-PressHUD/Level`、`G-PressureBar`、`G-ComboBadge`、`G-ResultLabel`、`G-ItemProgress`；`MCH-*`、`ITM-*`、`FX-PRESS-*`。

### S10 暂停

- 目标：安全冻结当前局，并提供继续、设置、重开和退出。
- 入口：S09/S11 右上暂停、系统切后台。
- 信息层级：“暂停一下” → “继续” → 声音/震动快捷项 → “重新开始”“退出本关”。
- 主要动作：“继续压”。
- 次要动作：声音、震动、减少动态效果、重新开始、退出本关。
- 出口：继续回原状态；重开经 S24 确认后回本关开头；退出经确认后回 S08 或模式来源页。
- 数据保护：切后台自动暂停；已完成物品保存为本局临时状态，主动重开才清除。
- 元素映射：`C-PauseModal`、`A-Button/Primary`、`A-Switch`、`A-Button/Danger`、`C-ConfirmModal`。

### S11 高塔粉碎

- 目标：展示本局方块高塔并完成蓄力、倒塔与精彩片段挑选。
- 入口：主关卡或今日订单最后一件完成；连续压结束后进入精简变体。
- 信息层级：高塔与高度“8.6 米” → 蓄力提示 → 冲击方向 → 倒塌分数增长 → “精彩片段已保存”。
- 主要动作：长按蓄力、松手粉碎。
- 次要动作：倒塌动画结束前无可点操作；结束后“看结果”。
- 出口：到 S12；生成回放失败也继续到 S12，并在结果页标记“本局未生成回放”。
- 元素映射：`G-TowerHUD`、`G-ChargeRing`、`G-TowerStack`、`G-ScoreTicker`；`MCH-HAMMER-01`、`FX-TOWER-*`。

### S12 关卡结果

- 目标：一次呈现星级、分数、结果分布和下一步，避免奖励层叠。
- 入口：S11 动画完成。
- 信息层级：“第 5 关完成” → 2 星 → 8,460 分/新纪录 → 完美 6、合格 2、失误 2 → 解锁进度 → 主要按钮。
- 主要动作：有下一关时“下一关”；主题末关时“查看主题奖励”。
- 次要动作：“再来一次”“分享精彩”“返回选关”。
- 出口：S09、S22、S08；产生奖励时以内嵌条展示，重大解锁才转 S13。
- 状态/反馈：不使用“失败”；未达解锁星数显示可重玩的改进提示。
- 元素映射：`G-LevelResultPanel`、`A-StarRating`、`C-ResultBreakdown`、`A-Button/*`；`ILL-RESULT-01`、`FX-REWARD-01`。

### S13 解锁奖励

- 目标：明确说明新获得的物品、模式、外观或主题，并给出单一下一步。
- 入口：S04 或 S12 检测到重大解锁；图鉴/成就里程碑。
- 信息层级：“解锁新东西！” → 奖励视觉 → 奖励名与用途 → 来源条件 → 主动作。
- 主要动作：物品为“去图鉴看看”，外观为“立即使用”，模式/主题为“现在体验”。
- 次要动作：“稍后再说”。
- 出口：按奖励类型到 S14/S19/S06/S07；稍后返回触发本弹窗的来源页。
- 元素映射：`C-RewardModal/Unlock`、`C-RewardCard`、`A-Button/*`；`ICO-REWARD-*`、对应物品/皮肤资产。

### S14 烦恼图鉴

- 目标：浏览至少 50 件物品及完成度，找到未收集的结果。
- 入口：底部“图鉴”、S13 物品解锁、S12 图鉴进度。
- 信息层级：总进度“已发现 8/50” → 主题筛选 → 物品网格 → 未发现提示。
- 主要动作：打开物品详情。
- 次要动作：主题筛选、仅看未完成、底部导航。
- 出口：S15；切换底部导航；根页返回遵循系统退出规则。
- 空状态：从未发现物品时展示 `ILL-EMPTY-COLLECTION` 与“完成首次按压就会记录第一件烦恼”。
- 元素映射：`C-CollectionGrid`、`C-CollectionCell`、`A-FilterChip`、`C-BottomNav`；`ITM-THUMB-*`、`ILL-EMPTY-COLLECTION`。

### S15 物品详情与三种结果

- 目标：展示物品材质提示，以及完美、欠压、过压三种可收集结果。
- 入口：S14 物品格、S13 新物品奖励。
- 信息层级：物品大图与名称“震动闹钟” → 材质“脆性” → 三结果分页 → 最佳记录/发现条件 → “去自由解压”。
- 主要动作：已解锁自由解压时“压一次”；未解锁时“去闯关”。
- 次要动作：切换结果页、查看来源关卡、返回图鉴。
- 出口：S16 或 S08；返回 S14 并保持筛选和滚动位置。
- 锁定态：未发现的结果显示轮廓与提示，不泄露完整事故画面。
- 元素映射：`C-ItemDetailCard`、`A-SegmentedControl`、`C-ResultVariantCard`、`A-MaterialBadge`；`ITM-DETAIL-*`、`ITM-RESULT-*`。

### S16 自由解压设置

- 目标：选择已解锁物品、传送速度和提示强度，进入无限次无失败体验。
- 入口：S06、S15。
- 信息层级：已选物品队列 → 速度“慢/标准/快” → 压力提示“始终/渐隐/关闭” → “开始解压”。
- 主要动作：“开始解压”。
- 次要动作：添加/移除物品、随机 5 件、调整设置、返回。
- 出口：自由解压 HUD 变体；暂停后可回本屏；无选中物品时主按钮禁用并提示“至少选 1 件”。
- 数据样例：已选 3/10：闹钟、橡皮鸭、纸杯；重复循环开启。
- 元素映射：`C-ItemPicker`、`C-SelectedQueue`、`A-SegmentedControl`、`A-Switch`；`ITM-THUMB-*`。

### S17 今日订单

- 目标：说明当天固定种子挑战、12 件清单、规则变化与个人完成记录。
- 入口：S05 今日订单卡、S06。
- 信息层级：“今日订单 · 8月27日” → 规则“理想区会缓慢移动” → 12 件预览 → 今日最佳/完成状态 → “开始订单”。
- 主要动作：“开始订单”或完成后的“再做一次”。
- 次要动作：规则说明、返回。
- 出口：今日订单 HUD 变体；完成后 S12 订单变体；返回来源页。
- 本地策略：使用版本化规则和本机日期确定性生成当日种子，离线完整可玩；本地配置损坏时进入 S24 错误态，可“重新生成”或“玩普通关卡”。跨日恢复先完成旧订单，再按当前本机日期生成新订单。
- 元素映射：`C-DailyOrderCard`、`C-RuleModifier`、`C-ItemPreviewStrip`、`A-StatusBadge`；`ILL-MODE-02`。

### S18 连续压与本地最佳

- 目标：解释逐渐加速规则，展示个人最佳，并开始无终点挑战。
- 入口：S06。
- 信息层级：“连续压” → 本地最佳“17 连击 / 23 件” → 速度阶段说明 → “开始连续压”。
- 主要动作：“开始连续压”。
- 次要动作：查看规则、清除本模式记录（需 S24 确认）、返回。
- 出口：连续压 HUD 变体；首次欠压/过压终止后进入本屏结果态，可重试或回模式页。
- 结果态：显示本次连击、压过件数、是否新纪录；不上传排行榜。
- 元素映射：`C-EndlessSummary`、`C-SpeedStages`、`A-StatusBadge`、`C-ConfirmModal`；`ILL-MODE-03`。

### S19 液压机外观

- 目标：预览并切换 10 套液压机外观和 5 套工坊背景，仅改变表现。
- 入口：底部“外观”、S13 外观奖励。
- 信息层级：舞台实时预览 → “液压机/工坊”分页 → 外观卡网格 → 解锁条件 → “使用中”。
- 主要动作：选择已解锁外观并“使用”。
- 次要动作：切换分类、查看锁定条件、恢复默认、底部导航。
- 出口：留在本屏预览；切换底部导航；返回遵循根页规则。
- 数据样例：默认“开工黄”；选中“薄荷冲压机”；锁定“火山锻压”需完成奇怪解压所第 15 关。
- 元素映射：`C-SkinPreviewStage`、`C-SkinCard`、`A-SegmentedControl`、`A-LockBadge`；`SKN-MACHINE-*`、`BG-WORKSHOP-*`。

### S20 趣味成就

- 目标：查看 30 个本地成就、进度和已领取的外观/图鉴奖励。
- 入口：S05 奖杯按钮、S13 成就奖励来源。
- 信息层级：“趣味成就 7/30” → 最近完成 → 分类筛选 → 成就列表。
- 主要动作：查看选中成就详情；存在未查看奖励时为“收下奖励”。
- 次要动作：筛选、返回。
- 出口：返回 S05；奖励领取后留在本屏；关联物品可到 S15。
- 空/完成态：无进度时展示可立即尝试的三项；全部完成时显示 `ILL-ACHIEVEMENT-COMPLETE`，仍可浏览。
- 元素映射：`C-AchievementRow`、`A-Progress`、`A-StatusBadge`、`C-RewardToast`；`ICO-ACH-*`、`ILL-ACHIEVEMENT-COMPLETE`。

### S21 设置

- 目标：统一管理声音、震动、压力提示、动态效果、存档和帮助。
- 入口：S05/S06/S14/S19 顶部设置；S10 快捷入口。
- 信息层级：音效、音乐、震动 → 压力条显示 → 减少动态效果 → 语言（v1.0 仅简体中文）→ 存档与关于。
- 主要动作：设置即时生效并本地保存，无单独“保存”按钮。
- 次要动作：“重看教学”“清除本地进度”“隐私说明”“返回”。
- 出口：返回来源页并保留其状态；危险操作均经 S24 二次确认。
- 错误/恢复：保存失败显示常驻提示“设置暂未保存”，提供“重试”并保留本次选择。
- 元素映射：`C-SurfacePanel`、`C-SettingsSection`、`A-Switch`、`A-Slider`、`C-SelectRow`、`C-ConfirmModal`。

### S22 录屏/分享预览

- 目标：预览本局 3–5 个精彩片段与倒塔结尾，确认后调用平台分享。
- 入口：S12“分享精彩”、成就/今日订单完成分享入口。
- 信息层级：视频预览 `VID-HIGHLIGHT` → 封面选择 → 时长“12 秒” → 分享说明 → “发布到抖音”。
- 主要动作：“发布到抖音”。
- 次要动作：切换封面、静音预览、重新生成、保存到本地（平台允许时）、返回结果。
- 出口：成功回 S12 并 Toast“分享成功”；取消回本屏；平台失败留在本屏并可重试或返回 S12。
- 离线/无回放：离线提供“稍后再试”；无有效片段提供静态成绩卡分享 `ILL-SHARE-CARD`。
- 元素映射：`C-VideoPreview`、`C-CoverPicker`、`A-Button/Share`、`C-ShareStatus`；`ILL-SHARE-CARD`、`DEC-SHARE-*`。

### S23 激励广告确认与奖励结果

- 目标：在克制的可选奖励点说明看广告的收益、时长和失败处理。
- 入口：关卡开始前神秘物品、结果页双倍图鉴材料、外观单局体验、分享特效包装。
- 信息层级：明确奖励 → “观看一段广告” → “看完才能获得” → 主要/取消按钮。
- 主要动作：“观看并领取”。
- 次要动作：“不用了”。
- 出口：完整观看显示同层奖励结果并“收下”；跳过/失败回来源且不惩罚；断网返回来源并提示不可用。
- 约束：不在连续按压中弹出；不使用焦虑倒计时；不把基础关卡继续权作为奖励。
- 元素映射：`C-AdRewardModal/Confirm`、`C-AdRewardModal/Granted`、`A-Button/Rewarded`、`A-Button/Cancel`；`ICO-REWARD-*`。

### S24 通用确认、错误、断网和恢复弹窗

- 目标：覆盖危险操作、资源错误、网络受限、存档恢复和生命周期恢复，不让流程进入死路。
- 入口：任意屏幕的确认/错误/离线/恢复事件。
- 信息层级：状态图标 → 明确标题 → 一句原因与影响 → 首选恢复动作 → 安全返回动作。
- 主要动作：按场景为“继续”“重新加载”“重试”“使用本地记录”“恢复本局”。
- 次要动作：“取消”“返回主入口”“退出本关”。
- 出口：成功回触发点；取消回原屏；不可恢复错误回 S05；退出游戏仅由系统返回触发确认。
- 约束：弹窗不堆叠；新弹窗先替换旧弹窗；破坏性操作按钮使用危险样式并重复说明将丢失的内容。
- 元素映射：`C-ConfirmModal`、`C-ErrorModal`、`C-OfflineModal`、`C-RecoveryModal`、`A-Button/*`；`ICO-STATE-*`。

## 4. 产品范围参考

1. 以上24类条目用于防止遗漏玩家需求，可以合并成更少的页面及状态，不要求在Figma中建立24张独立画板；不新增独立商城、个人中心、排行榜或社交页。
2. 主导航固定为“闯关 / 模式 / 图鉴 / 外观”，设置与成就为页面级入口。
3. 首次体验必须完成三件物品与一次倒塔后再解锁完整入口，不能跳过。
4. 主关卡没有传统失败或生命值；欠压和过压降低表现但不中断关卡。
5. 激励广告只出现在四类可选奖励点，不阻止基础进度。
6. 全部进度、成就与最佳成绩为本地数据；不提供排行榜。
